# Sentinel LLM

Sentinel LLM is an AnythingLLM governance-control-plane project for verifiable activity, deterministic policy enforcement, and governed agentic execution.

The repository is currently in its instruction and planning bootstrap stage. Implementation must follow [PROJECT_PLAN.md](PROJECT_PLAN.md) and the Codex coordinator in [AGENTS.md](AGENTS.md).

Specialist Codex operating manuals live under [`agents/`](agents/). The pack manifest and installation notes are under [`docs/agent-guides/`](docs/agent-guides/).
